# أداة الأرشفة (WPF)

تطبيق **WPF** بسيط بلغة **C#** لأرشفة الملفات في نظام ويندوز داخل ملف مضغوط بصيغة `zip`. يتيح التطبيق:

- إضافة ملفات متعددة إلى قائمة الأرشفة.
- حذف ملفات محددة أو مسح القائمة بالكامل.
- اختيار مكان حفظ الملف المضغوط وتحديد مستوى الضغط.
- إنشاء الأرشيف مع التعامل مع التكرارات أو الأخطاء الشائعة.

## طريقة التشغيل

> يتطلب بناء المشروع وتشغيله نظام ويندوز مع تثبيت **.NET 6 SDK** أو أعلى.

1. افتح المشروع:

   ```bash
   cd ArchiveApp
   dotnet build
   dotnet run
   ```

2. من واجهة التطبيق:
   - استخدم زر **إضافة ملفات** لاختيار الملفات.
   - اضغط **اختيار** لتحديد مكان حفظ ملف الأرشيف (`.zip`).
   - حدد **مستوى الضغط** ثم اضغط **إنشاء الأرشيف**.
